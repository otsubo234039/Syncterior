# 家具取り込み用の自作サンプル

`furniture-desk.glb`は、この試作のために箱5個から作成した机です。幅1.2m・奥行き0.6m・高さ0.8mの形状と、自作の2×2pxの模様を埋め込んでいます。実在の商品や外部配布モデル・画像は使用していません。

机の形状は`src/features/room-planner/utils/__tests__/helpers/furniture-glb.js`と同じ定義で、サンプルにはUVとPNGテクスチャを追加しています。圧縮・アニメーション・外部参照は含みません。家具の形状を保証する製品データではなく、取り込み・寸法調整・配置を試すためのものです。
