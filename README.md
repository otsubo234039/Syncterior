# Syncterior

ROOM/PLAN — React Three Fiber 3D家具配置シミュレーター

Coding agent向けの開発・コミット規約は [AGENTS.md](AGENTS.md) を参照してください。

## ディレクトリ構成

```text
.
├── frontend/          # React / Vite / React Three Fiber
│   ├── src/           # app・共通UI・機能単位の実装
│   ├── index.html
│   ├── package.json   # フロントエンド専用の依存関係・コマンド
│   └── package-lock.json
├── backend/           # バックエンド（未実装）
│   ├── src/
│   └── README.md
├── .gitignore
└── README.md
```

フロントエンド内部の構成・依存ルールは [frontend/README.md](frontend/README.md) を参照してください。

フロントエンドとバックエンドは、それぞれのディレクトリで依存関係・設定・起動・ビルドを管理します。バックエンドの実行環境は未選定です。実装時は `backend/` に専用の依存関係定義やロックファイルを配置してください。

## フロントエンドの起動方法
Node.js 20.19 以降を用意し、リポジトリのルートから次を実行します。

```bash
cd frontend
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

ビルドとビルド結果の確認も `frontend/` で実行します。

```bash
npm run build
npm run preview
```

ビルド成果物は `frontend/dist/` に出力されます。バックエンドについては [backend/README.md](backend/README.md) を参照してください。

## 実装内容
- React + Vite + React Three Fiber / Three.js
- ワンルーム、1LDK、ファミリー向けの3種類の間取り
- ソファ、ベッド、ローテーブル、デスク、椅子、テレビ台、冷蔵庫、フロアランプ
- 家具の選択、追加、移動、90度回転、削除、色変更
- 一般的な家具・家電寸法をメートル単位で表示
- OrbitControlsによる3D視点操作、レスポンシブなUI
- 個人配置のブラウザ内への自動保存・復元、保存内容の消去
- OpenCV.jsによる感度指定なしの間取り画像の壁候補抽出と3D化
- 図面上の任意の2点と一辺の実測値によるサイズ合わせ、個人保存

## 操作
- 左側の間取りカードで部屋を切り替え
- 家具カタログを押して配置
- 3D内の家具をクリックして選択
- 家具をドラッグして移動（移動中は視点を固定し、ドラッグ終了後に視点操作を再開）
- 「90°回転」で向きを変更
- プロパティ欄で位置と色を調整
- 右上のゴミ箱ボタンで選択中の家具を削除
- 「間取り画像から3Dの枠を作る」で画像を選び、測った一辺の両端を図面上で指定して実際の長さを入力し、「この枠で3Dを作成」を押す。詳細は[取り込み手順](frontend/README.md#間取り画像から3dの枠を作成issue-28)を参照

## 注意
これは初期プロトタイプです。寸法は一般的な目安で、実際の住宅図面・製品寸法との一致は保証しません。個人配置は同じブラウザ内に保存します。画像からの壁候補抽出には誤検出や欠落があり、床は仮の長方形です。結果を確認し、測った一辺の長さでサイズを合わせてください。詳細な形状編集は将来の2D図面モードで扱う方針です。取込間取りは枠の表示・実寸補正・個人保存専用で、家具配置と共有は未対応です。サーバーへの永続保存と衝突判定も未実装です。
