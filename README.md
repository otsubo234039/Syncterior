# Syncterior

ROOM/PLAN — 2D図面の作成・保存と、React Three Fiberによる3D家具配置シミュレーター

Coding agent向けの開発・コミット規約は [AGENTS.md](AGENTS.md) を参照してください。

## ディレクトリ構成

```text
.
├── frontend/          # React / Vite / React Three Fiber
│   ├── src/           # app・共通UI・機能単位の実装

├── backend/           # バックエンド（未実装）
```

フロントエンド内部の構成・依存ルールは [frontend/README.md](frontend/README.md) を参照してください。

フロントエンドとバックエンドは、それぞれのディレクトリで依存関係・設定・起動・ビルドを管理します。バックエンドの実行環境は未選定です。実装時は `backend/` に専用の依存関係定義やロックファイルを配置してください。

## フロントエンドの起動方法
Node.js 20.19 以降を用意し、リポジトリのルートから次を実行します。

```bash
cd frontend
npm install
npm run dev
```

ローカルでは `http://localhost:5173/` を開きます。開発サーバーは5173番に固定し、IPv4でも接続できるよう全インターフェースで待ち受けます。5173番が使用中の場合は別ポートへ自動変更せず起動時にエラーを表示します。

Codespacesでは「ポート」タブの5173番を「ブラウザーで開く」から表示してください。ポートはPrivateのまま利用します。手元のブラウザの`localhost`は手元PCを指すため、Codespacesの転送URLを使ってください。バックエンドやE2E専用の4175番はアプリの表示先ではありません。

5173番が起動済みなら追加の起動は不要です。転送URLでGitHubへのログインや「Codespaces Access Port」の確認画面が出た場合は、自分のCodespaceへのアクセスを確認して「Continue」を押します。詳しくは[接続の確認手順](frontend/README.md#起動済みなのにページを開けない場合)を参照してください。

ビルドとビルド結果の確認も `frontend/` で実行します。

```bash
npm run build
npm run preview
```

ビルド成果物は `frontend/dist/` に出力されます。バックエンドについては [backend/README.md](backend/README.md) を参照してください。

## 実装内容
- React + Vite + React Three Fiber / Three.js
- ワンルーム、1LDK、ファミリー向けの3種類の間取り
- ソファ、ベッド、ローテーブル、デスク、椅子、テレビ台、冷蔵庫、フロアランプ
- 家具の選択、追加、移動、90度回転、削除、色変更
- 一般的な家具・家電寸法をメートル単位で表示
- OrbitControlsによる3D視点操作、レスポンシブなUI
- 個人配置のブラウザ内への自動保存・復元、保存内容の消去
- 画像なしでの2D作図、図面のブラウザ内保存・復元、JSONファイルの入出力
- OpenCV.jsによる間取り画像から編集可能な2D図面への変換と、図面からの3D生成
- 図面上の任意の2点と一辺の実測値によるサイズ合わせ、個人保存

## 操作

- 初期画面の「図面モード」でグリッドを使って壁・床・扉・窓を編集します。「壁を追加」は2点指定、「線を消す」は壁1本の削除です。
- 「図面の新規作成・読込・画像変換」から新規作図、保存図面やJSONファイルの読込、間取り画像の変換を行います。
- 画像変換では、任意の2点と実測値で全体のサイズを合わせ、「図面へ変換」で編集へ反映します。元画像は下絵として使えます。
- 「図面を保存」は3Dを開かずに利用できます。保存はこのブラウザ内の1図面で、JSONファイルでも持ち出せます。
- 「図面から3Dを表示」で立体化し、「3D・家具配置」で家具の追加・移動・回転・色変更・削除を行います。同じ図面の修正では家具を維持し、収まらない変更は拒否します。新しい画像や別図面からは家具なしで生成します。
- 家具配置の「平面図」「3D」で表示を切り替え、「初期視点」「正面」で3D視点を変更できます。

詳しくは[図面モードの操作](frontend/README.md#図面モードissue-19--50)を参照してください。

## 注意
これは初期プロトタイプです。寸法は一般的な目安で、実際の住宅図面・製品寸法との一致は保証しません。個人配置は同じブラウザ内に保存します。画像からの壁候補抽出には誤検出や欠落があり、床は仮の長方形です。結果を確認し、測った一辺の長さでサイズを合わせてください。画像なしの新規作図は指定した寸法の床から始めます。図面モードで下絵を見ながら壁・床・開口を修正し、3Dとは別に図面を保存できます。取込間取りでも家具を配置・編集・個人保存できます。共有は未対応です。サーバーへの永続保存と家具同士の衝突判定は未実装です。
