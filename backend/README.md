# バックエンド

APIや永続保存など、サーバー側の実装を配置するディレクトリです。現在は未実装で、起動コマンドはありません。

実装項目・未決定事項・完了条件は[バックエンド未実装項目・引き継ぎ](docs/implementation-backlog.md)を参照してください。実装や仕様変更時には、この一覧も更新します。各項目の実装Issueも同じ一覧で追跡し、新たなバックエンド対応が必要と判明した場合は既存Issueを確認して不足分を起票します。

- `src/`: サーバー側のソースコード
- 言語・フレームワーク選定後、依存関係定義、ロックファイル、テスト、実行設定をこのディレクトリ内に追加します。
- 環境変数を使用する場合は、値を含まない `.env.example` を配置し、実際の値は Git 管理対象外の `.env` で管理します。
- フロントエンドとは HTTP API を介して接続し、互いのソースコードを直接 import しない構成にします。

実装時にセットアップ・起動・テスト手順とAPI仕様への参照をここに追記してください。
